# Blooming Beauty Skin

Full-stack skincare ecommerce platform for Cambodia. The project is a pnpm/Turborepo monorepo with:

- `apps/web`: Next.js 14 storefront and admin panel
- `apps/api`: Express API, Prisma, PostgreSQL
- `packages/shared`: shared TypeScript types/constants

## Requirements

- Node.js 18+
- pnpm
- Docker, for the local PostgreSQL and Redis services

## Environment

Create app env files before running locally:

```bash
cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env.local
```

Important values:

- `DATABASE_URL`: PostgreSQL connection used by Prisma.
- `JWT_SECRET`: must be the same in `apps/api/.env` and `apps/web/.env.local`.
- `CORS_ORIGIN`: frontend origin allowed by the API.
- `API_INTERNAL_URL`: server-side target for the Next.js `/api/*` rewrite.
- `NEXT_PUBLIC_API_URL`: optional. Leave empty/unset to use same-origin `/api`.
- `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` and `NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET`: required for admin image uploads.

## Local Development

Start infrastructure:

```bash
docker compose up -d postgres redis
```

Install dependencies:

```bash
pnpm install
```

Prepare the database:

```bash
pnpm db:migrate
pnpm db:seed
```

Run both apps:

```bash
pnpm dev
```

Useful URLs:

- Web: `http://localhost:3000`
- API: `http://localhost:4000`
- API health: `http://localhost:4000/health`

## Verification

Preferred checks:

```bash
pnpm lint
pnpm build
```

Package-local fallback checks, useful if the pnpm/Corepack shim cannot verify the pinned package manager in an offline shell:

```bash
cd apps/web && ./node_modules/.bin/next build
cd ../api && ./node_modules/.bin/tsc --noEmit
cd ../../packages/shared && ./node_modules/.bin/tsc --noEmit
```

## Project Scripts

Root scripts:

- `pnpm dev`: run web and API through Turbo
- `pnpm build`: build all packages
- `pnpm lint`: lint all packages
- `pnpm db:migrate`: run Prisma migrations
- `pnpm db:seed`: seed sample data
- `pnpm db:studio`: open Prisma Studio

App scripts:

- `apps/web`: `dev`, `build`, `start`, `lint`
- `apps/api`: `dev`, `build`, `start`, `lint`, Prisma database scripts

## Notes

- Auth uses an httpOnly `token` cookie. Do not store the JWT in localStorage or return it to the browser as readable data.
- The web app proxies `/api/*` to the Express API through `apps/web/next.config.js`.
- PWA service worker files under `apps/web/public/sw.js` and `apps/web/public/workbox-*.js` are generated by the build and ignored by git.
